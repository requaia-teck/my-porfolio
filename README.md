## 🛠️ Technologies Used | التقنيات المستخدمة
* **HTML5:** لإنشاء هيكلية الموقع بشكل صحيح ومنظم.
* **CSS3:** لتصميم الموقع وإضافة لمسات جمالية (تنسيق الألوان، الخطوط، والأنيميشن).
* **JavaScript:** لإضافة التفاعل والحيوية للموقع.
* **Responsive Design:** الموقع متوافق مع كافة الشاشات (موبايل، تابلت، حاسوب).

---

## 📂 Project Structure | هيكلة الملفات
* `index.html` - الصفحة الرئيسية.
* `css/` - ملفات التنسيق الأساسية.
* `responsive.css` - ملف خاص لجعل الموقع يعمل بامتياز على الهواتف.
* `script.js` - ملف التفاعلات البرمجية.
